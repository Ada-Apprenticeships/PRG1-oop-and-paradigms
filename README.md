# PRG1: Objects, and comparing paradigms (PRIM activities)

Day 9. Six activities plus two stretch folders, in one repository used across
both sessions.

## PRIM

| Step | What you do |
|---|---|
| **Predict** | Say what the code will do **before** you run it. Write it down. |
| **Run** | Run it. Compare against your prediction. |
| **Investigate** | Work out *why* it behaves that way. |
| **Modify** | Change something specific, predicting the effect before each change. |

Activities 5 and 6 work differently. There is nothing to predict, because you
already know what the programs do. They are about comparison and evidence.

## The activities

### Session 1: reading object oriented code

| Folder | Focus |
|---|---|
| `activity-1-reading-a-class/` | One class: what an object knows, and what it can be asked to do |
| `activity-2-two-objects/` | Two objects from one class, and what `self` is standing in for |
| `activity-3-objects-holding-objects/` | A car park made of bays, which is the shape that matters |
| `activity-4-broken-classes/` | Three faults in class code that runs perfectly happily |

### Session 2: the same program, two ways

| Folder | Focus |
|---|---|
| `activity-5-the-same-program-twice/` | One car park, written procedurally and with classes |
| `activity-6-the-change-experiment/` | Make the same two changes to both, and record what happened |

Activity 6 is paired and is the point of the day. What you write down at the end
of it is most of the answer to the assignment task released this afternoon.

### Stretch

| Folder | Focus |
|---|---|
| `stretch-1-inheritance/` | One class built on top of another |
| `stretch-2-getters-and-setters/` | Deciding what outside code is allowed to change |

Neither stretch folder is needed for any assignment task. They are there because
you will meet both in real code, not because you are assessed on them.

## One car park all day

Activities 1 to 6 are all the same car park, growing from a single bay to two
complete programs. Only what the code does with it changes.

## How to work through these

Work in pairs. One drives, the other reads and questions, then swap at each new
activity. Activity 6 swaps at each change.

You are **not** expected to finish everything. Activity 3 in session 1 and
activity 6 in session 2 are the two that matter.

## Running a file

```
cd activity-1-reading-a-class
python bay.py
```

If `python` is not recognised, use `python3` instead.
